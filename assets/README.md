# WordPress.org Plugin Assets

This directory contains assets required for the WordPress.org plugin repository.

## Required Assets

### Banner
- `banner-772x250.png` - Plugin banner for WordPress.org (required)
- `banner-1544x500.png` - High-resolution version of the banner (optional but recommended)

### Icon
- `icon-128x128.png` - Plugin icon (required)
- `icon-256x256.png` - High-resolution version of the icon (optional but recommended)

### Screenshots
Place screenshots in the `screenshots` directory. Name them sequentially:
- `screenshot-1.png` - First screenshot
- `screenshot-2.png` - Second screenshot
- etc.

## Design Guidelines

### Banner
- Keep it simple and visually appealing
- Include your plugin name
- Use a consistent color scheme with your brand
- Avoid small text that will be unreadable

### Icon
- Simple, recognizable design
- Works well at small sizes
- Consistent with your brand

### Screenshots
- Show the most important features of your plugin
- Include captions in the readme.txt file that explain each screenshot
- Use clear, high-quality images
